# مُصْحَفُكَ

موقع عربي متجاوب للقرآن الكريم والأذكار والأدعية والأحاديث ومواقيت الصلاة. الواجهة مبنية بـ React وTypeScript وVite، مع Tailwind CSS، ودعم RTL، ومظهر فاتح/داكن/حسب النظام.

## التشغيل

يتطلب Node.js 20 أو أحدث.

```bash
npm install
npm run dev
```

أوامر التحقق:

```bash
npm run typecheck
npm run lint
npm test
npm run build
```

لا تحتاج نسخة التطوير إلى مفاتيح أو متغيرات بيئة. يعتمد التطبيق على مصادر عامة عبر الإنترنت، ولا يطلب حسابًا أو إذن تحديد الموقع.

## محتوى الموقع

- **القرآن الكريم:** قائمة السور المحلية كخيار احتياطي، ونص السور من AlQuran Cloud. آخر موضع قراءة محفوظ محليًا.
- **التفسير:** تفسير الميسّر (`ar.muyassar`) من AlQuran Cloud بجوار نص الآيات.
- **الأحاديث:** صفحات من سنن أبي داود عبر `hadis-api-id.vercel.app`. يعرض الموقع المتن العربي ورقم الحديث واسم المجموعة، ولا يضيف ترجمة أو حكمًا على درجة الحديث. راجع المصدر المختص قبل اعتماد النص للنشر العلمي.
- **الأدعية والأذكار:** من ملف `azkar-api` العام المثبّت على نسخة مصدر محددة. لا يُنشئ الموقع مراجع؛ يعرض المرجع فقط عندما يكون موجودًا في البيانات.
- **مواقيت الصلاة:** Aladhan API مع اختيار يدوي للمدينة والدولة وطريقة الحساب. القيمة الافتراضية طريقة الهيئة المصرية العامة للمساحة، ويمكن اختيار طريقة أخرى.

تعرض الصفحات ما توفره المصادر دون إعادة صياغة النصوص الدينية. قد لا يقدم المصدر مرجعًا تفصيليًا لكل دعاء أو ذكر؛ في هذه الحالة لا يخترع الموقع مرجعًا.

## التخزين والعمل دون اتصال

تُحفظ تفضيلات المظهر، والمحفوّظات، وموضع القراءة، والمدينة، وتقدّم العدّاد على الجهاز باستخدام `localStorage`. يخزّن التطبيق أيضًا آخر استجابات المحتوى الصالحة، وتسجّل خدمة `Service Worker` غلاف الموقع واستجابات API التي سبق تحميلها.

تعمل الواجهة دون اتصال بعد زيارة الموقع، لكن نصوص القرآن والأحاديث والتفسير الكاملة لا تُضمّن كلها داخل الحزمة. يتوفر دون اتصال فقط ما سبق تحميله وحفظه، إضافة إلى قائمة أسماء السور المحلية.

## النشر

أُعدّ المشروع للنشر كتطبيق Vite ثابت. أمر `npm run build` ينشئ `dist/` ويولّد صفحات دخول ببيانات SEO منفصلة للصفحات الرئيسية وصفحات السور الـ114. إعدادات Vercel وإعادة كتابة المسارات موجودة في `vercel.json`.

الملفات التي كانت موجودة قبل إعادة البناء—بما فيها `legacy-index.html` ومجلدات `CSS/` و`Images/` و`JS/` و`pages/`—ما زالت محفوظة في المستودع. نقطة الدخول الحالية هي `index.html` وتطبيق React في `src/`.

## الوصولية والخصوصية

يدعم الموقع لوحة المفاتيح، ومؤشر تركيز واضحًا، ورابط تجاوز إلى المحتوى، وتقليل الحركة، وأحجام نص قابلة للتعديل في قارئ القرآن. لا يستخدم تحديد الموقع التلقائي أو أدوات تتبّع. عند إدخال مدينة، تُرسل المدينة والدولة إلى Aladhan API لطلب المواقيت.
